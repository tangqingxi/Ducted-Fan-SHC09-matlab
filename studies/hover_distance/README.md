# hover_distance：悬停偏差与偏航代价

本场景位于新分支`hover_distance`，从PPID-PINDI工作树新建，原有未提交修改全部保留。入口为根目录`run_hover_distance.m`。旧F8/PPID协议、正式驱动、控制器、分配器、旧锁及旧结果不改。

**当前仅完成两条种子501预检，正式批未启动。** 预测PCA正常缩放占空比15.0%达到10–30%要求，但最小λ=0.00823089未达到0.3–0.6。没有调整验收门槛或用分位数代替最小值，也没有创建新正式锁。完整报告见根目录`codex-repo-6.md`。

## 固定场景与复用范围

| 项目 | 设置 |
|---|---|
| 规划位置 | NED [0,0,−10] m，位置/速度/加速度保持悬停 |
| 规划姿态 | 滚转、俯仰为0；内部姿态指令仍由共用位置/速度环纠偏生成 |
| 偏航 | 机体角速度参考峰值280°/s、0.75 Hz正弦，0–2 s起振、38–40 s收振 |
| 偏航角/角加速度 | 对平滑速率解析积分/求导，不读真值、不数值差分估计器 |
| 滚转干扰 | 0.5 Hz正弦，10 s加载、22 s开始卸载，0.5 s五次平滑过渡 |
| 滚转权限 | 由现有axis_capacity_nm读取，当前1.213133995 N·m |
| 实际设定幅值 | 85%×上述模型权限=1.031163896 N·m；并非用户初估的约1.7 N·m |
| 时长/评价窗 | 40 s；主窗[10,22)s，恢复窗[22,32)s |
| 正式计划 | DA_NS/WLS/DCA/PCA_STATIC/PCA_PREDICTIVE × 501/502/503 |

权限来自名义悬停力矩矩阵的各轴区间映射，不是实机测量。父场景的M2b舵效、真实舵机24–40 ms/名义30 ms、±40°、600°/s等保留；原F8的0.6偏航外扰移除，只有本场景滚转外扰。

`ppid_config`构建共用配置后，新文件只替换时长、参考和外扰。`ppid_control_step`、`ppid_noise`、传感器/ECL、`ppid_simulate`和分配器直接复用，控制增益与噪声不改。父仿真器有一个52秒EKF频率统计分母，新包装层在40秒日志中修正该统计元数据；物理积分、控制、传感器和PWM时钟不变。其52秒PWM缓冲预分配只影响内存，最终按实际事件截断。

为复用原生外扰插值，`cfg.disturbance_type="random"`字段承载**预先生成的确定性正弦序列**。随机力矩幅值设为0，experiment中的序列替换为同一确定性序列；不是额外随机干扰。所有随机测量过程仍按父噪声模型生成。

## 信息与评价

所有方法共享需求生成公式、控制器参数、名义B、舵角估计模型、时钟与上下界。PCA保留nu_h、缩放nu_c；其余取和。各方法的nu_h/nu_c、估计舵角和已下发指令会随闭环作用分叉，不能强行复用另一方法的状态。共用的是信息规则、规划参考、初态与随机误差过程，不是分叉后的数值序列。

沿用用户此前选择，以**估计反馈域**的水平距离和滚转误差为主，真值并列。800 Hz状态评分，400 Hz控制判定缩放与回退，100 Hz展示；窗口右端不重复计时。λ<1只统计mode0有限λ，mode1/2独立报告，缺失λ不填1。PWM缩放事件按实际333 Hz下发所采用的最新400 Hz分配结果计数。

恢复时间定义为22 s后第一次连续0.5 s满足：估计水平距离≤0.2 m、水平速度≤0.2 m/s、滚转绝对值≤2°。报告进入时间和确认时间，未达到保留缺失。同时报告恢复窗峰值及相对22 s偏差方向的反向超调，禁止事后平移或真值对齐。

`protocol.json`在首次飞行前写定预检条件。用户明确给定λ占空比10–30%、最小值0.3–0.6及mode1≤5%；对“伪逆偏航跟踪正常”另设了70°/s工程检查线。伪逆无扰段约4.1°/s，但干扰段149.6°/s未过该工程线。即使不采用这一额外工程线，预测PCA的λ最小值仍独立未满足用户要求。

本次未触发“λ全为1”或“mode1>5%/发散”的调参分支，未尝试90%、300°/s或75–80%。若用户批准把λ最小值过低也作为降载触发，再仅用501尝试80%/75%，重新跑成对预检；不改控制器或噪声，也不把正式种子波动用于整定。

新结果目录以`results/hover_distance_`开头。预检完整MAT与轨迹保留；轻量表图见`examples/hover_distance_precheck_20261102/`。单种子伪逆对照不能代替五方法主表或预测/优先级消融；没有统计显著性、实机优势或全局最优结论。
