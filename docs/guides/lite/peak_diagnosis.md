# v0.5 修复前：lite 主窗姿态峰值诊断

> 文档类型：证据。修复前诊断，按记录时状态理解。

诊断先于估计器修改。基线v0.4.0=`9594ce8`，30条M0/M2b×五方法×seeds1:3的20秒lite日志，仅离线读取、无新增仿真。M0从原暂停目录按log_key读取；M2b/lite在该目录未运行，按HANDOFF从完整恢复目录读取。主窗仍[6,16]，峰值仍原rotation_error_rad；另定位全程峰值，不改指标或窗口。

直接证据：seed1五方法均在10.9秒越过5°，不是某个分配器独有。以M0/WLS为例，真实滚转3.654°、估计滚转1.921°、姿态参考滚转−1.529°；真实/参考滚转角速度−7.060/−27.498°/s。相邻1.25ms跟踪误差由3.201°跃至5.452°，参考跳2.335°，估计姿态仅变0.00919°。同一时刻估计位置跳0.16287m、速度跳0.12276m/s，符合GNSS新观测的0.1+0.2k秒时钟。

外环为a_ref=Kp(p_ref−p_est)−Kv v_est。用日志中的估计位置/速度离线重算参考旋转，与已记参考的矩阵误差全部<1e−10。因此直接触发链为：lite的离散GNSS修正→位置环参考倾角阶跃→姿态/速率环追赶；不是姿态测量或陀螺偏置瞬间跳变。M0/WLS滚转v_h/v_c=+0.858/−4.269rad/s²，M2b/WLS为−0.865/−4.306；v_h范数约60主要来自偏航负载补偿，不能据总范数认定它主导滚转峰值。峰值舵命令最大约29.3/30.8°，实际舵角约25.3/27.2°，均指WLS，未触公共40°限幅；DCA和预测PCA在seed1/2峰值处触及命令限幅，但未限幅的三种静态方法也同步超限，限幅并非该共同尖峰的必要条件。全部六通道值、三轴角速度/参考、偏置与邻域见CSV。

分类：加载实际在2秒，6秒只是主窗起点；seed2/3全程峰值多在2.3～2.5秒，与加载有关，但本次主窗超限集中10.9秒，非6秒加载或16秒卸载。峰值远离15秒静置对准结束，不能由初始化残留单独解释同步参考跳变。当前证据是测量驱动的反复修正及闭环响应，尚不足以宣称自主全程极限环。姿态估计背景误差仍约1～1.8°，不能把全部误差只归因一个尖峰。

第一轮修复假设（在试验前固定）：只在lite估计器内部把GNSS位置/速度的离散互补修正连续注入，保持原低频融合增益、原始噪声/偏置、Mahony kp/ki及所有控制器不变。统一时间常数0.1s，来自5Hz观测周期的一半，不按方法/种子选择；不做姿态真值兜底。须以全部三种子、五方法的主窗峰值/饱和/估计RMS检验，最多两轮内部迭代。这个机制可能增加导航修正滞后，不能只看峰值下降而忽略其他门禁。
