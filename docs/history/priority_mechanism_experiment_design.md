# 优先级机制触发实验设计：偏航抗扰与横向机动争用六舵面

> 文档类型：历史。

本文件保留最初经过冻结可达性核对的设计。随后已完成80%负载主工况、小幅慢速对照及WLS权重敏感性检查，见 `../results/priority_pilot_L80_A200_20261030/report.md`。实际动态闭环的可行lambda区间可能不包含零，未在每个时刻满足下列原设计强判据，不能把冻结证明直接当成闭环证明。

## 核心判据

不能只增加扰动幅值。需要同时出现：

1. 补偿需求vh单独处于可达集合内。
2. 总需求vh+vc处于集合外。
3. vh与vc明显不共线，主案例取偏航补偿与滚转跟踪。
4. 优先射线有0<lambda<1的可行解，且优先级作用保持足够长时间。

可达集合同时核对静态集合和共同PWM评价终点的动态集合。还需区分预测PCA保守指令约束对应的子集合与真实限速模型的完整终点集合，不能将保守性造成的不可达误报为物理不可达。

当前INDI的vh含alpha_reference。直接提高姿态参考频率，会把很大的参考角加速度也放进高优先级项，可能直接使vh不可达，触发回退而非正常优先级缩减。因此主案例改为位置指令机动：沿用当前位置外环的姿态指令方式，角速度/角加速度前馈为零，机动初期的跟踪需求主要进入vc。

## 物理场景与时间安排

采用真实六自由度SHC09，目标高度10m，初态为悬停配平；控制、传感器、滤波、PWM、舵机及限幅全部保持五方法相同，不降低某个基线的控制增益。

| 时间/s | 指令与环境 | 目的 |
|---|---|---|
| 0～2 | 固定点、无额外外力矩 | 校验无约束时的共同基线 |
| 2～3 | 用0.5秒平滑过渡施加恒定偏航负载 | 避免未滤波的突然外力矩直接让补偿估计失配 |
| 3～4 | 保持位置和偏航负载 | 让补偿舵角、滤波和估计器进入负载工作点 |
| 4～10 | 在同一高度向东侧机动，位置参考以0.15秒平滑过渡，在+2m/−2m间每1.5秒切换 | 大滚转跟踪需求与偏航补偿争用舵角和短期动态能力 |
| 10～12 | 回到固定参考并撤除偏航负载 | 检查恢复和残余误差 |

位置参考切换应进入统一参考模块，不针对分配器改变。固定点下的偏航抗扰、机动时的位置误差和恢复时间同时报告，允许PCA为了稳定偏航牺牲机动速度；不要求所有误差指标同时最优。

## 按物理能力预先设定负载

当前模型在悬停点的纯偏航静态控制能力约0.51940N·m。风扇/固定片残余偏航扭矩约−0.094923N·m。

采用三个预设补偿占用率50%、65%、80%，对应控制补偿扭矩0.25970、0.33761、0.41552N·m。为了在稳态得到这些补偿，外部偏航负载分别约−0.16478、−0.24269、−0.32060N·m。初始纯偏航补偿的最小范数舵角分别为20°、26°、32°，均在±40°物理范围内；80%案例保留8°正向静态舵角余量。

横向2m位置误差经当前位置增益产生约14.876°滚转参考。机动初期，当前公共姿态/角速度增益对应约1.0795N·m的滚转跟踪需求。该值由模型和固定任务计算，未通过哪个方法表现最好来选择。

三个负载全部保留，包括可能显示DCA同样保持补偿的案例。主机制检验可看80%负载，同时报告50%、65%以及正负机动方向，避免只展示有利边界。

## 已核对的冻结输入证据

在偏航补偿已建立、保持命令等于当前舵角的共同状态，采用同一PWM相位和同一评价终点：三个负载均由独立LP证明vh可达，vh+vc不可达。

80%负载时，单PWM终点的代表结果：

| 分配器 | 偏航补偿实现比例 | 滚转跟踪实现比例 | 正常/回退 |
|---|---:|---:|---|
| DA_NS | 99.711% | 3.602% | 正常 |
| WLS | 99.711% | 3.602% | 正常 |
| DCA | 99.711% | 3.602% | 正常 |
| 静态PCA | 100.000% | 3.211% | 正常，静态lambda约0.3371 |
| 预测PCA | 100.000% | 3.211% | 正常，动态lambda约0.0321 |

这里的静态lambda与动态lambda属于不同评价时域，不能直接比较大小当作优劣；表中效果均按共同单PWM终点重算。该冻结例只证明可发生优先取舍，偏航实现差距约0.289%，不能据此宣称闭环大幅提升。

50%和65%负载时，DCA在这个冻结状态同样完整保留偏航补偿，说明“进入边界”不自动保证PCA与DCA显著分开。完整三负载结果均在`results/priority_design_20261030/geometry_grid_frozen_comparison.csv`，可达性证书在同目录`geometry_grid_feasibility.csv`。

另有外部偏航−0.16N·m、横向2m的计算，静态最高跟踪比例约0.858，真实单PWM可达集合最高约0.0506，预测PCA保守约束下约0.0482。两套可达集合的差异须明确记录，不把预测器保守性当成优先级本身的收益。

## 对照组与评价

- 不受限对照：50%偏航补偿负载，小幅慢速横向参考（如0.2m、0.8秒过渡），检查是否大部分时刻仍为lambda=1。
- 主冲突组：50%、65%、80%负载和固定2m横向机动，核对补偿可达、总需求不可达的实际持续时长。
- 超负载对照：让补偿本身超过可达域，只用于检查回退和失败标记，不能作为正常优先级优势的证据。

统一报告：偏航角/角速度误差、横向位置误差和机动完成时间、舵命令步变与饱和、正常lambda<1时长、mode1/mode2比例、求解异常、气动表越界及对名义/实际舵效的敏感性。

独立LP按统一时钟核验可达性；边界和采样窗口预先固定，不依据某个方法误差挑选。另将五种闭环各自记录的冻结输入回放给全部五分配器，比较同输入结果，避免因各方法闭环状态不同误解补偿需求。

主实验先保留共同30ms时间常数与现有噪声滤波，分清优先级机制。之后再对所有方法统一增加时间常数失配，作为独立鲁棒性因素；不通过故意让DCA模型更差来制造优势。

注意：完整闭环中vh会随反馈改变。若大部分时刻补偿本身不可达、气动表越界或状态失稳，这个设置不能当作正常优先级试验，必须如实标记并重新讨论任务边界。原冻结结论与后续闭环结论应分开引用，实际执行结果及下一步方向见上述报告。
