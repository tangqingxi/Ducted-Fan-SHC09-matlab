## 传感器设计和公开假设

| 项目 | 默认值/实现 | 解释 |
|---|---|---|
| 陀螺噪声 | 任务给定ICM-20689典型0.004°/s/√Hz，100Hz一阶噪声带宽 | sigma=0.004*sqrt(pi/2*100)=0.05013°/s；离散AR(1)生成，初值为稳态分布 |
| 陀螺偏置/游走 | [0.03,−0.02,0.04]°/s；0.01°/s/√s | 都是假设，不是本轮实测识别；游走增量按sqrt(dt)缩放 |
| 加计 | sigma=0.03m/s²；偏置[0.04,−0.03,0.06]m/s² | 比力R转置*(a−g)，不是把加速度真值送给滤波器 |
| 磁计 | 50Hz、10ms；sigma=.003G，偏置[.001,−.001,.002]G | 固定公开参考场[.22,0,.43]G，是匹配场模型假设 |
| 气压 | 50Hz、30ms；sigma=.3m、偏置+.4m | 测量高度−down，延迟缓存存传感器值 |
| GNSS | 5Hz、100ms；位置sigma=[.5,.5,.8]m，偏置[.2,−.15,.3]m；速度sigma=.1m/s | 位置/速度独立流，只在到达时标记fresh |
| 地转/重力 | 7.292115e−5rad/s按公开纬度分解；名义g=9.788m/s² | 估计器用估计姿态扣除地转，不用真实姿态 |
| 独立种子 | lite_seed=72001，各噪声分量使用不同子种子 | 每工况/种子/模式只预生成一份输入，五方法共用 |

CUAV V5 Nano三IMU在这里仅以任务指定典型噪声代表主IMU，不实现多IMU投票、校准或硬件自动选择。100Hz参数用于噪声带宽近似，不宣称完整硬件ADC/信号传递函数已标定。辅助传感器沿用已有sigma而非重新识别谱密度。偏置/游走、磁场、所有延迟均是公开仿真假设。

lite与ECL共用现有偏置及辅助观测的噪声/频率/延迟配置字段，没有第二套隐藏偏置定义。按本轮保留ECL路径的约束，ECL仍使用历史陀螺sigma白噪声；lite新增密度/带宽噪声及游走，oracle也保留旧噪声。因此跨模式对比是估计与测量链整体变化，不是单独姿态真值的因果消融。

## lite观察器与固定参数

姿态采用Mahony式向量互补观察器：由加计重力和磁计TRIAD初始化R，陀螺积分，重力/磁向量叉乘创新比例修正及偏置积分。仅采用该观察器结构，不声称本实现满足原文全部稳定性条件。参考[Mahony等，Nonlinear Complementary Filters on SO(3)，2008](https://researchportalplus.anu.edu.au/en/publications/nonlinear-complementary-filters-on-the-special-orthogonal-group/)，DOI 10.1109/TAC.2008.923738。

| 配置 | 数值 | 作用 |
|---|---:|---|
| lite_attitude_kp | 2/s | 旋转创新比例修正，两向量等权 |
| lite_attitude_ki | .05/s² | 陀螺偏置积分 |
| lite_position_tau_s | 2s | GNSS位置互补时间常数 |
| lite_velocity_tau_s | .5s | GNSS速度互补时间常数 |
| lite_baro_tau_s | 2s | 气压垂向位置修正 |
| lite_gnss_timeout_s | 2s | GNSS长期无效时停止 |
| lite_max_innovation_rad | π/4 | 向量创新范数门禁（小角近似量），不是真实姿态误差 |
| navigation_warmup_s | 15s | 支撑静置、传感器对准，不计任务性能窗 |

位置/速度由估计R旋转比力后加g积分，GNSS位置用测量速度补偿已知延迟，气压用估计垂向速度补偿，再按时间常数融合。初始化来自GNSS测量，不取真实位置或参考目标。lite是简化互补观察器，不是ECL、完整卡尔曼滤波或带协方差一致性证明的导航器。

所有增益在看E1/E2比较排名前固定，未按方法或结果搜索。静止对准是明确的起飞前支撑假设；持续线加速度会污染加计重力修正，磁偏置、位置偏置和匹配场模型限制精度，健康标志不等于真实误差保证。

## 真值隔离与失败行为

- lite/ECL分支不发布sensor_attitude或sensor_local_position；没有plant_truth topic。
- lite模块签名为bus、滤波状态、白名单参数和时间；不接收plant state、模型对象、真实偏置或扰动。初始化只能读取测量，参数视图对改变真实偏置不变。
- 控制器measured姿态逐采样与vehicle_attitude估计矩阵相同；原控制函数和五种算法原字节不变。lite独占vehicle_angular_velocity，原测量滤波仅发布角加速度及历史舵角。
- 非有限IMU、创新/数值异常、GNSS长期无效会发布health=false，sim立即assert停止，不接入真值或旧估计代替。首帧NaN故障注入已验证仿真停止。
- estimated_attitude_error_rad、estimated_position_error_m、estimated_gyro_bias_error_rad_s是sim私有离线真值误差，只写日志，不反馈。
- 对准负时间与任务零时间统一映射缓存源时间；已用移动位置斜坡检查实际延迟载荷、时间戳和采样率，避免只有元数据看似正确。

## DCA优势变化的回答

E1中静态PCA/DCA的平均姿态误差比由ideal的12.208降为lite的1.0369；相对静态PCA的误差改善由约91.8%缩为约3.56%。预测PCA在lite中为0.990917°，DCA为0.990803°，差别约0.0115%，不宜称为具有实际显著性的排名。

E2主窗中DCA由ideal的0.000973°变为lite的0.842712°；静态PCA为0.840636°、预测PCA为0.840747°。静态/DCA比0.99754，DCA不再领先。预测PCA比DCA低约0.23%，但这一单种子微小差别不构成统计显著性或普遍优越性证据。

本次估计/测量链的约0.7～1.2°姿态误差已大于oracle下方法之间的差异，明显压缩动态分配的可见收益。不能把变化全部归因于姿态真值，更不能据此测出精确tau的贡献，因为传感器噪声结构也变化、tau仍匹配。E2没有优先级机制收益的独立证明，M4仍未测试。


## 结论边界与未做事项

E3未运行，所以没有估计反馈下M4/M2b/M3的比较证据。不能把E2 M0结论推广成M4收敛差异仍存在/消失，也不能从原oracle稳态推导估计反馈的全动态鲁棒性。原第二轮30/30轻量示例和结论保持原样，本轮不重跑正式阶梯。

DCA没有得到私有姿态真值，五方法共用反馈与名义参数；oracle的理想姿态、匹配tau确属全平台有利假设，动态算法可能从这些条件中获得更可见的收益。新结果应按具体工况和主指标解释，不把公共理想假设称作某算法偷看真值。

本轮不做HIL、完整EKF2、实机标定、多IMU投票、完整执行器失配或参数不确定性。lite没有完整滤波协方差、传感器故障管理或持续加速保证；磁场模型匹配也是假设。

长批处理完成全部断言和验收记录后，MATLAB曾在退出阶段停留；已清理本次验证进程，存档由独立MATLAB进程重新加载、断言核验并正常退出。退出停留仍是已知平台限制，不能把该CLI退出问题混淆为算法数值失败或宣称已彻底修复。

CSV导出按实际存在的估计量处理，不把lite当成ECL；ECL旧指标表经独立相等性比较逐位保持。lite没有ECL故障码或计算耗时的地方用NaN显式标明，不虚构健康诊断。控制链从来不读取这些离线评估字段。


## 追加核验与停止点

传感器级lite测试在独立-nojvm进程通过，ECL及正式基线回归仍使用JVM。日志元数据修改后，ideal完整冻结基线再次逐位一致，14项旧测试与6项平台测试再次通过。它们不覆盖或消除上面的物理偏置失败。

E2主窗里预测PCA的PWM步变RMS约2.2889°，DCA约2.6003°（低约12%），但其饱和比例2.1915%高于DCA的1.9213%；静态PCA步变仅0.3307°且无饱和，不能宣称预测PCA所有指标最优。这些都是未验收候选估计器下的单种子观察。

E1的record诊断只统计控制采样点，0%不替代error对所有物理子步的严格门禁；E2使用原协议error策略。没有把未运行的M4估计反馈结果补成结论。

已停止后续算法修改、参数搜索和新增试验；保留代码、全部已完成CSV、真实失败记录及可重现失败的测试，等待用户决定下一轮估计器设计方向。
