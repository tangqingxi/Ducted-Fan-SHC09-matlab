# 第二轮结构失配基准

> 文档类型：历史。

默认配置继续使用`aero_low_speed_model="legacy"`、阈值1m/s。历史配置缺少这两个字段时也使用legacy。默认物理输出经冻结上一轮源码和既有参考测试逐位核对；新低速字段不进入分配器配置或名义model。

`hold_90`在V≤阈值时令涵道查表角为90°，保留原机翼Vvw≤1m/s时取90°的规则。固定状态扫描发现，直接硬切换在悬停转速下最大力差为重量的2.5423%，1200rad/s为3.5392%，所以在[阈值,2×阈值]内用三次平滑权重混合90°分支及原角度分支的涵道力/力矩。此处混合力而不混合迎角；V>阈值时门禁始终检查原始角度，表外就报错，不能借过渡区绕过表格范围。V≥2×阈值回到原方程。机翼原阈值仍保留，最终边界力差最大为重量的0.124258%，不是严格处处连续的完整气动模型。

“低速影响小”是待量化的假设，不能无条件把所有角度相关项称为小于2%重量：方程还包含V×转速交叉项，已经实测导致上述硬切换超限。V²查表项、交叉项和边界差异应分别看待。该正则化不是表外豁免，也不是实飞识别结论。

主协议为20秒固定位置[0,0,-10]m，2秒开始加载、16秒开始卸载、过渡0.5秒，主评价窗6～16秒（含卸载开始瞬间，其扰动值尚未改变）。负载默认0.6、允许0.4～0.8。保留`protocol_mode="pilot_12s"`的旧位置阶跃，仅供对照。导航ideal、真实与名义tau均30ms、不缓变，只隔离对象舵效。公共控制器及五分配器不修改。

M0/M1/M2/M2b/M3/M4依次为中性、统一1.2倍、交替1.2/0.8、[1.2,1,0.8,1,1.2,1]、三号0.7、特征角28°的tanh。M2主要改变零空间；M2b使名义行空间分配也出现实际误差。`cases.csv`保存行空间和零空间算子范数。M4使用同一个名义负载工作点（60%时六舵24°）的局部导数，指标不是全局常量，也不是实际稳态舵角。

WLS主设置[1,1,1000]，另在M0/M3固定比较[1,1,1]及[1000,1000,1]；敏感性不混入主排名，不搜索权重。全部方法同一份参考和公共随机流，种子沿用20261029/43001/24001，单组配对试验不构成统计显著性证据。

按执行顺序先低速/协议/回归和两秒烟雾，再单独20秒M0 legacy/hold_90对照，解释差异后运行M0/M3及M4筛查，最后完整30次。默认fail_fast=false，普通求解失败保存后继续；已知V>阈值的气动表错误必须整体停止，空速无法确认也保守停止。烟雾用fail_fast=true。失败不写虚假的完整log，status/failure保留失败，summary只有completed，plan_status列出未运行项。

输出追加低速正则化比例、保留原位置指标并标为secondary；瞬态与全程另有whole指标，不能只报稳态掩盖启动/卸载代价。结果均写入新目录，原结果不覆盖。源码快照及依赖气动表保留。后续执行器/估计器阶段不在本轮实施。
