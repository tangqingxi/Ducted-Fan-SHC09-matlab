# F8-P-v1：有限偏航压力试验的条件预案

> 2026-11-01预先写定，尚未进行本预案任何轨迹仿真。只有完整F8-v1两组都缺少持续优先级激励时才执行。不得改写[F8-v1](f8_protocol.md)或把开发筛选追认为独立确认。

[机器协议](../../configs/f8_pressure_protocol_v1.json)定义三个候选：60°/0.75 Hz、60°/1 Hz、75°/1 Hz的正弦偏航，使用与位置轨迹相同的平滑运动时钟；相位起止平滑、最终回到零航向和零角速度。位置仍严格为F8-D的3/1.5m半幅、10秒巡航周期八字。偏航角幅度不等于合成倾角，不将45°倾角包线误用于航向角。

设计依据是名义控制余量：现有静态偏航能力约0.5194 Nm，0.6负载约占0.3116 Nm；仅60°、1 Hz正弦偏航的惯性力矩峰值就约0.2070 Nm。两者合计已接近静态名义能力，动态滞后还会影响可达性。这是必要的激励量级估计，不是对闭环性能、真实推力或PCA优越性的预测。高低优先级近乎共线时，即使λ缩放也不证明优先级方向保护；仍使用原几何夹角与可行性证据。

全部门槛、时间窗口、0.6负载、M2b气动倍率、五算法、物理、估计器、反馈增益和舵机假设不变。本预案只是仿真压力假设，不代表已经验证真实飞行器可以执行这些偏航角速度。

开发阶段仅用独立种子9002，三个候选各跑WLS、静态PCA、预测PCA，共9条，完整保留不利结果。只有PCA满足原全部任务要求、WLS与PCA均数据有效且在包线内，同时满足以下条件之一，才进入确认：PCA通过而WLS任务未通过；或水平位置/航向RMS至少一项改善5%，其他跟踪RMS不恶化超过5%。全程PWM步变RMS还须不超过WLS的2倍，以避免用巨额舵机活动代价包装微小跟踪收益。

若多个候选有希望，优先选参考偏航角速度峰值最小者，再按角加速度峰值最小者选择；不按确认结果挑选。以上是明确披露的目标导向开发筛选，不能用开发点证明泛化优势。

确认只用预留种子201–203，所选单一候选跑五方法，共15条；按原F8门禁、同种子配对差值和全部箱线图呈现。开发无候选通过就停止，不继续扩大搜索、不改门槛、不伪造最好组。最多新增24条。确认失败也保留，不返回开发阶段追逐有利种子。

实现为[参考构造](../../studies/legacy_experiments/ca_f8_pressure_protocol.m)、[有限运行入口](../../studies/legacy_experiments/run_f8_pressure_study.m)与[前馈导数测试](../../tests/test_f8_pressure_protocol.m)。运行入口强制读取已完成基础批次的条件记录，确认入口还须读取开发选择记录，不能绕过开发阶段自行挑确认轨迹。[参考预检](../validation/f8_pressure_protocol_v1/reference_preflight.csv)与[单元检查](../validation/f8_pressure_protocol_v1/checks.json)不含任何压力仿真结果。
