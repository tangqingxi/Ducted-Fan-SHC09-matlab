# F8-P-v2：在合格八字基线上进行有限偏航压力比较

> 自适应设计，2026-11-01，在任何压力候选仿真前写定；不是宣称最初就预注册了此版本。它替代尚未执行的[F8-P-v1预案](f8_pressure_protocol.md)，保留旧预案与变更原因。F8-v1的30条基础结果仍完整呈现，不改写已观察到的未通过项。

[机器协议](../../configs/f8_pressure_protocol_v2.json)是唯一数值来源。原F8-v1所有门禁、0.6负载、M2b气动倍率、物理、五算法、估计器、反馈增益、执行器及时间窗口保持不变。没有为了通过高度门槛而修改公共控制器或数值门槛。

## 为什么改变尚未执行的压力预案

F8-R已完成五方法三种子，15/15通过全部任务要求；F8-D首个种子的多种方法出现高度RMS约0.228m超过0.20m。离线力分解显示，F8-D的来流气动相对静态推力映射平均产生约0.225m/s²向下缺口，高度估计平均偏差仅约1.5cm，电机滞后项很小。这个公共推力控制瓶颈不应被包装成分配器优劣。因此将压力试验的位置基线由F8-D换成已合格的F8-R，不根据某个分配器胜出选位置基线。

另一项新证据是：F8-R中预测PCA相对静态PCA的PWM步变约11.5倍，但实际主窗舵速RMS约1.64倍。命令变化不是实际运动，更不是能耗或磨损；v2将开发筛选的代价条件明确改为真实舵机运动，PWM代价仍单列。此变更发生在压力试验之前，不能把它追认为旧预案已经通过。

## 固定参考、筛选与确认

- 位置：严格沿用F8-R的N/E半幅3/1.5m、巡航周期20s、两圈、z=-10m和原平滑运动时钟。仍比最初2/1m的八字有更大的速度与加速度激励。
- 偏航候选：60°/0.75Hz、60°/1Hz、75°/1Hz正弦，均沿同一平滑运动时钟起止。45°合成倾角包线不误用于航向角。
- 开发：固定独立种子9002，三个候选各跑WLS、静态PCA、预测PCA，最多9条；全部保留。
- 有希望条件：PCA满足原全部任务要求，WLS与PCA均数据有效且在包线内；同时PCA通过而WLS任务失败，或者水平位置/航向RMS至少一项改善5%、其他跟踪RMS均不恶化超过5%。
- 实际运动代价：主窗真实舵速RMS与真实舵角总行程分别不超过WLS的2倍；PWM步变仍报告，不冒称机械损耗。不得在结果出来后继续放宽此条件。
- 多个有希望候选时，选参考偏航角速度峰值最小者，再按角加速度峰值最小者选择。开发无有希望候选即停止，不扩大搜索。
- 确认：所选单一候选五方法×未查看的保留种子201–203，共15条；不按确认结果改选轨迹或种子。开发筛选有目标选择偏差，不能当成独立确认或泛化证据。

最多增加24条压力/确认轨迹；v1压力预案不再另跑。优先级机制条件仍按原高优先级可行、全需求不可行、夹角与持续时间门槛独立评价。预测改善若发生在λ=1的条件下，只能说明这组实现的动态预测/恢复差异，不能称为受限优先级保护的证明。两个版本的源文件、配置与输入摘要分别记录。

三个候选的[解析参考预检](../validation/f8_pressure_protocol_v2/reference_preflight.csv)及[单元核验](../validation/f8_pressure_protocol_v2/checks.json)已完成，不含压力轨迹仿真。[运行入口](../../experiments/run_f8_pressure_study.m)以`protocol_version=2`区分两个版本，并强制检查基础结果、合格位置基线与开发选择记录；后处理脚本还核对20个相关源码/协议摘要，避免运行中改参考或门槛。
