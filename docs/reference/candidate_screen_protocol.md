# 八字与定点抗扰有限工况筛查

> 文档类型：参考。

本轮目标是寻找预测PCA在明确任务指标上的适用优势，不要求所有指标同时第一。筛查与后续重复确认分开；所有候选、失败及代价保留。

首轮运行前固定三种工况：

1. `figure8_T8`：N/E半幅2m/1m，基础周期8秒，完整两圈；速度用2秒五次平滑函数起停，初始和终止均静止。4秒开始，22秒完成，26秒结束。
2. `figure8_T12`：相同几何路径，基础周期12秒；4秒开始，30秒完成，34秒结束。
3. `hover_turning`：NED位置固定[0,0,-10]m；2秒建立偏航负载，6/10/14秒依次切换为名义能力归一化坐标的+35°/−35°/0°俯仰偏航混合补偿方向，18秒卸载，22秒结束。

首轮补偿负载均为各方向名义射线能力80%，平滑转向0.75秒；两种八字均保持纯偏航补偿方向。真实舵效随物理状态改变，80%只指悬停名义标定，不宣称运动中始终占用实际能力的80%。

五方法为DA_NS、WLS、DCA、静态PCA、当前最小变化恢复的预测PCA。本轮WLS明确取等轴归一化权重[1,1,1]，与前期默认滚俯高权重[1000,1000,1]分开记录，不按结果重配权重。公共位置/姿态/INDI控制、六自由度模型、噪声、PWM、执行器参数不改变；未向任何分配器提供未来扰动或真实执行器状态。

主评价：八字从开始到完成两圈，定点抗扰4～18秒。初筛判据预先固定为：预测PCA偏航RMSE比四个基线最小值再低至少5%，位置RMSE不比基线最优值恶化超过5%，五方法均完成且主评价窗无气动表外推。阈值是本轮筛查规则，不是统计显著性或实机性能指标。仅某个单项更好而未通过位置条件的案例仍报告，不能称为通过该综合规则。

全部保存任务/整段/恢复期误差、命令步变、触边、回退、缩减、求解失败、气动表越界和耗时。WLS和DA的分支标志不解释为PCA补偿回退。候选单种子20261029，各方法逐点随机输入相同。只有找到有实际差距的候选后，再进行新种子或邻域参数确认，不用时间采样代替重复试验。

现有公共位置外环没有轨迹速度或加速度前馈，连续八字将有明显公共跟踪滞后；本轮不修改控制器追求有利排名。实际误差和几何轨迹必须一起报告，不能仅凭偏航较小就声称高精度轨迹跟踪。

运行入口`main_candidate_screen`；`plot_candidate_screen`只读取已有结果。可用新结果标签重跑，不覆盖旧结果。正式运行配置、完整参考、随机输入、模型和源码快照分别存入各层MAT文件。

首轮完成后，三个工况均未出现PCA正常优先级缩减或回退，DCA偏航误差均略小于预测PCA，因此追加一个独立标签的边界补测：仅将8秒周期八字的名义补偿占用从80%提高到98%，其余条件及初筛判据不变。该补测是根据首轮结果作出的适应性实验设计，不冒称最初三工况的一部分。所有首轮不利结果保留。
