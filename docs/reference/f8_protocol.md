# F8-v1.0：平滑八字与偏航跟踪协议

> 文档类型：当前研究协议。2026-11-01，在第一条正式 F8 轨迹仿真前写定；此前八字结果全部作为开发探索。数值来源以[机器可读协议](../../configs/f8_protocol_v1.json)为准。门槛是预先声明的研究任务要求，不是经实测验证的安全包线，也不是 PX4 的统一验收标准。

## 为什么另立协议

旧 M0/M2b 的 5°、10% 饱和占比等门禁不用于判定 F8 任务资格。代码 `rotation_error_rad` 是真实姿态相对本次外环期望姿态的 SO(3) 旋转误差，不是相对水平的倾角。即使明确了这个区别，直接用近悬停协议排除动态任务仍缺少任务依据。旧结果和旧判定原样保留；此前选出的 42 秒大半径候选不视为新任务的获选方案。

F8 分开评价数据有效性、飞行包线、任务跟踪品质与优先级激励。触及舵角限制是受限分配实验要观察的行为，不因饱和占比超过 10% 自动删除轨迹。没有激励出优先级，不等于轨迹数据无效；也不能据此证明优先级保护效果。

|高度|NED z=-10 m；F8-R 两圈，F8-D 四圈|
|反馈与对象|lite，显式启用 GNSS 速度辅助；M2b 线性气动失配及原 0.6 偏航负载；800 Hz 控制、333 Hz PWM|

## 前馈怎样进入控制链

新分支只在 `f8_feedforward_enabled=true` 时启用；旧位置控制函数和旧配置的算术路径保留。位置与速度反馈增益仍为 [1.3,1.3,1] 与 [3.2,3.2,2.1]；姿态和角速度增益仍为 8 与 12，不按方法分别调参。

`a_cmd = a_ref + Kp .* (p_ref - p_est) + Kv .* (v_ref - v_est)`。

保持原水平 4 m/s² 与竖直 ±4 m/s² 的加速度限制；新分支另加 45° 合成倾角限制和最大静态推力 90% 的命令上限，在总推力约束内优先保留竖直分量。没有积分器，不冒称移植了 PX4 的完整 PID 或积分抗饱和逻辑。

由参考加速度、jerk、snap 和航向的一、二阶导数解析计算名义几何姿态、机体系角速度及角加速度，送入已有几何姿态环。前馈向量转到反馈修正后的期望机体系；它是名义几何前馈，不声称等于受反馈修正、限幅和估计噪声影响的最终姿态指令的精确导数。不对估计姿态数值差分，不消费对象真值或未来观测。已知计划轨迹可以提前求导。

十二状态图使用共同几何参考 p/v、名义几何姿态和机体角速度；另报实际反馈姿态与角速度指令跟踪误差，不能把各方法不同的内环目标误称为共同外部目标。十二状态仍不是十二个可独立指定的自由度。

## F8 自己的门禁

先查数据有效性：每场景 15/15、0 失败、0 未运行；同种子共同参考和随机输入；有限状态；无真值反馈；无气动表越界。无效轨迹保留错误记录，不生成成功结论。

|类别|逐次运行要求；主窗含平滑起止 [6,50] s|
|---|---|
|包线，检查全程|真实合成倾角 ≤45°；舵机命令和实际偏角 ≤40°；离散记录的实际舵速 ≤600°/s；电机命令对应的名义静态推力 ≤模型最大值的 90%|
|位置任务|水平位置向量 RMS ≤0.5 m、峰值 ≤1.5 m；高度 RMS ≤0.2 m、峰值 ≤0.5 m|
|速度任务|三维速度向量 RMS ≤0.5 m/s|
|航向任务|折返航向误差 RMS ≤5°、峰值 ≤15°；航向本身不受 45° 倾角上限限制|
|内环与估计|相对实际期望姿态的旋转误差 RMS ≤5°、峰值 ≤20°；姿态估计旋转误差 RMS ≤2°|

以上跟踪数值是工程任务需求，特意在新路径正式结果产生前声明，并非从旧轨迹的峰值加余量凑出来。某次未通过就如实报告；全方法任务满足需要每个方法的三个种子均通过。未通过的方法仍画箱线图并标出失败，不通过删样本制造可比性。不生成与旧悬停 `rankable` 混用的标签，不合成为掩盖代价的单一总分。

优先级机制另加激励要求：运动主窗内 mode0 且 λ<1−1e−6 的累计时长 ≥0.1 s，最长连续段 ≥0.02 s；至少两个种子满足；独立名义几何审计须确认高优先级可行、全需求不可行，且高低优先级夹角 ≥15°。单有短促启动触发或 nominal residual 接近零都不满足机制证据要求。即使条件满足，也只能解释当前场景，不能证明预测 PCA 普遍优于其他方法。

## PX4 依据和推力估计

参考固定为 PX4 **v1.16.0**，不把不断变化的 main 分支当成可重复实现。

用户另提供的专用[DuctedFanUAV-Autopilot 参考核查](ductedfan_autopilot_reference.md)固定到 `df-main` 的 `2e53639`，核实了谐波八字、前馈消费、SHC09推力映射、参考模型与优先级前置条件。该核查不改变已经写定的v1参数；若以后移植其完整INDI或参考模型，另立版本。

- [PositionControl.cpp](https://github.com/PX4/PX4-Autopilot/blob/v1.16.0/src/modules/mc_pos_control/PositionControl/PositionControl.cpp)：位置误差贡献叠加到速度设定，速度反馈贡献叠加到加速度设定；包含倾角限制、推力分配及其抗饱和处理。这里借鉴前馈设定值的叠加关系，没有复制其完整控制器。
- [AttitudeControl.cpp](https://github.com/PX4/PX4-Autopilot/blob/v1.16.0/src/modules/mc_att_control/AttitudeControl/AttitudeControl.cpp)：标准路径明确加入 NED 竖轴航向角速度前馈；不据此宣称 PX4 自动使用本协议完整的三轴角加速度前馈。后者是本仓库已有几何姿态环支持的接口，由 F8 解析参考提供。
- [位置控制限制参数](https://github.com/PX4/PX4-Autopilot/blob/v1.16.0/src/modules/mc_pos_control/multicopter_position_control_limits_params.c)：`MPC_TILTMAX_AIR` 默认 45°，适用于速度／加速度控制模式的倾角限制；不是所有模式的通用姿态误差上限，也不是本飞行器能力证明。

用户补充的“遥控器油门杆约 70% 时静态推力 2100 gf”只确定该设置下的悬停点；杆量会受飞行模式、曲线、悬停映射及电机模型影响，不能当作转速 70% 或归一化推力 70%。实机最大推力与倾角极限仍未知。

无气动附加力、无爬升的点质量估计为 `T cosθ = W`，所以 `θ_max = acos(W/T_available)`。若保留 10% 推力余量，使用 `T_available=0.9 T_max`。当前模型静止轴向最大推力为 `2.8964e−5 × 1200² = 41.70816 N`，重量 20.5548 N；理想极限约 60.5°，保留 10% 后约 56.8°，再由协议限制到 45°。这不是有来流、侧向气动力、力矩配平和电池压降时的实机极限。

用用户给出的 2.1 kgf 悬停推力作直观换算：30° 保高约需 2.425 kgf，45° 约需 2.970 kgf；保留 10% 推力余量时，45° 要求最大可用推力至少约 3.300 kgf。原完整气动模型的冻结力扫描由[audit_f8_thrust_envelope.m](../../analysis/audit_f8_thrust_envelope.m)执行，不把该扫描称为完整配平或控制权证明。
