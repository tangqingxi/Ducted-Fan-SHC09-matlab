# SHC09 物理对象校对记录（2026-10-30）

结论：原对比对象属于固定悬停点的三轴转动模型，足以做分配机制和理想基线分析，不能代表完整 SHC09 六自由度闭环。参考工程有更丰富的物理方程，但也存在数据覆盖范围和控制器真值反馈等假设；不能将“与该代码一致”当成“已经证明实机精度”。

## 从参考工程移植的内容

物理部分按源方程保留：导航系风速转机体系、涵道/机翼三次样条、出口速度、六舵面实际效能、被动力矩、重力/外力及欧拉刚体方程。平动使用中点积分，姿态采用旋转指数映射，避免欧拉角奇异点。真实和估计舵机仍分别推进，PWM保持时刻仍精确定位。

`InnerLoopController_new.m` 使用 State.Ve 构造效能，且读取 Actuator.u 实际舵角；`Output2Actuator_new.m` 又写入 24.2452m/s 和 `[0.3,0.3,0.06]` 力臂的 B_hat，与物理初始化 `[0.267,0.267,0.066]` 不一致。本次未照搬这些控制接口。五分配器只得到相同的名义效能、模型舵角及公共测量链，避免给某个算法额外真值。

参考工程的初始出口速度24.2452只是其控制/状态初始化值，按这套环境和物理参数重新算的静止悬停值为24.2304。配平是从物理参数推得的公共初态，并非通过闭环结果调参。

## 气动数据的适用范围

原表涵道迎角为0～130°、机翼为−20～130°；实际计算迎角通常在0～180°。参考代码 ppval 会在表外继续外推，没有单独报告。本项目默认保留源行为并逐采样标记、统计和提示，另可设置 `aero_extrapolation_policy="error"` 在积分中点等任意物理计算越界时停止。

固定悬停转速、只跟踪姿态时，倾斜造成垂向推力损失，物理对象真实下沉，气流迎角可能超过130°。六秒姿态检查中约44.9%～45.1%的控制采样点外推；以DCA为例六秒末下沉约1.20m。即使空速低、部分外推项很小，也不能省略这一适用范围说明。该组用于发现模型/任务设定问题，不作为性能优越性的最终证据。

带 `[1,-0.5,0]m/s` 风的六秒位置保持检查，五方法的控制采样点均无外推。风速、随机力矩、噪声均为敏感性设定，没有被当成实机标定。

## 已完成验证及结果

- `test_shc09_physics`：40个随机状态，含不同速度、姿态、转速、舵角、风和外力，与源 SHC09_Sys 逐项核对。
- 平动加速度最大差异约1.78e-14m/s²，角加速度约1.42e-13rad/s²，出口速度约7.11e-15m/s。
- 初始配平加速度和角加速度接近机器精度，历史舵角滤波器按配平稳态初始化。
- 固定执行器20ms动态段与高精度ode45参考比较：800Hz/1600Hz状态最大误差约9.10e-9/2.28e-9，符合二阶收敛。
- 原分配冻结输入、WLS独立最优性、PWM时钟、两种PCA原闭环回归、传感器链和随机试验组织检查通过。
- 两个场景、五方法、每个6秒，十次数值运行均完成，无求解失败或回退。输入在同场景方法间严格配对。

姿态场景有效窗内RMS（仅供功能检查，含外推）：DA_NS/WLS/静态PCA约0.23367°，DCA约0.11178°，预测PCA约0.11355°。物理对象扩充没有自动使预测PCA超过DCA。

位置模式当前外环没有角速度前馈，偏航仍跟踪变化参考，姿态RMS约2.07°。这不是对完整位置控制器性能的标定，不能与直接姿态跟踪场景的RMS混用。

结果目录：`results/shc09_6dof_audit_attitude_20261030` 和 `results/shc09_6dof_audit_position_20261030`。它们保存了当时源码/配置快照。新增的物理汇总CSV由已保存日志计算，不修改原试验日志。完整物理验证在 `results/validation/shc09_physics.mat`。

## 尚未解决的实机精度问题

一阶舵机时间常数、速率限制与测量噪声仍需实测识别；未建立时变/负载相关时间常数、死区、回差、舵面相互干扰及结构振动。参考方程本身也未把舵面侧向力加入总平动力，没有提供此处可独立验证的完整风洞/实飞精度。当前模型没有地面接触、地效或完整导航估计误差模型。六自由度结构更完整，参数精度仍需外部试验支撑。
