# 原文核对与SHC09适配

核对日期：2026-10-29。共同平台为SHC09六舵面姿态闭环，无推力/位置/高度控制；各分配器只读取同质量的估计状态。所有方法的真实执行器及PWM完全相同。

## CN109976368B

来源：[专利原文](https://patents.google.com/patent/CN109976368B/zh)，已核对步骤(1)–(10)及公式图片。

先最大化`rho`，满足`B*u=rho*target`及幅值界；超过完整需求时缩回，再求伪逆解。超限则按分段偏置G、尺度H、并列极值集合及最小正步长执行零空间迭代。

本平台使用角加速度等式，对原力矩等式左乘惯量逆不改变可行解。本实现只面向对称舵角界。并列极值导致零空间子矩阵奇异时用广义逆；迭代上限或数值停滞时按原流程缩放，明确记录，不用QP替代。实际舵机速率限制由公共物理模型执行。

## Smeur等WLS

来源：[IMAV 2017论文](https://www.imavs.org/papers/2017/6.pdf)，第3节、式(6)、Algorithm 1及第3.1/3.2节。

保留增量WLS和通道权重。六舵面平台删除推力及旋翼转动惯量项。增量围绕当前估计偏角，首选绝对输入为零舵角，故首选增量为负当前估计偏角。

三轴按`sum(abs(B_i).*command_upper)`归一化，再用权重`[1000,1000,1]`、`gamma=1e8`和单位归一化输入权重。权重可覆盖。活动集以可行中点初始化，消除原文初始化和/差写法的歧义。两组权重的独立最优性测试不等于完成闭环调参。

## Venkataraman等DCA

来源：[2004论文](https://www.math.ttu.edu/~rvenkata/Papers/ieeeconf2004-1.pdf)，式(11)–(18)及数值例。

一般定义在时间区间求执行器输入；数值例采用当前起点的单点区间、0.02秒步长及受限二阶执行器。不能将一般形式直接当成固定长窗口MPC。

这里采用共同一阶限速模型、默认一个PWM周期的单步推进及终点物理力矩二范数误差。需求在该步冻结，不读取未来参考；`dca_horizon_s`可覆盖。步长、模型和终点离散化均为SHC09适配。

受限一阶模型的终点对指令连续单调。指令上下界经完整模型映射成精确终点区间，以`lsqlin`优化终点力矩误差，再二分反解指令。因此速率饱和已进入可达集合，不给DCA额外施加预测PCA的保守非限速约束。

内部直接从当前估计状态预测新指令，不加入等待旧指令阶段；真实平台仍按共同PWM等待。原生预测与公共评估器预测分开保存。本适配不代表原框架无法加入等待时序。

## PCA两组

复制旧实现的单纯形、恢复器及包装。静态分配使用B；预测分配先按旧指令推进至下发点，再预测完整保持周期，并限制`abs(c-delta_at_delivery)<=tau*rate`保证仿射关系成立。

补偿可达时完整保持，再最大化跟踪比例；不可达时只缩放补偿，仍不可行时最小化其无穷范数残差。不能缩放既有偏角延续项。恢复分别保持`B*c`和`B*G*c`不变。优先关系限定于统一终点，无一般闭环稳定性保证。
