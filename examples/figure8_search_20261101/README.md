## 结论与诊断

8/8仿真完成，运行失败0；八个候选WLS/seed2预筛都没有通过原5°姿态误差峰值、10%饱和、2°姿态估计RMS及气动越界0的共同门禁。没有修改门禁；本轮未找到合格的更激进轨迹，也未启动只对合格候选开展的五方法×三种子15次确认。不能据此声称五方法都失败，只能说必要的WLS预筛条件已经失败。

最接近者F42_A4p5_Y20：姿态误差峰值5.35666495°，仍超5°；相对位置RMS约0.3493。峰值发生在8.605秒，当时姿态估计误差2.1057°、位置估计误差0.5345m、速度估计误差0.2374m/s、实际舵角最大29.2085°。不是碰到40°机械限幅。

离线用真实位置/速度重算同一时刻外环参考，只用于诊断，不馈入控制器；与估计反馈生成的参考差约6.739°。这说明导航状态误差会显著改变外环指令，但这种冻结反事实不是另一个闭环实验，不能据此量化修复收益。

代码核查显示lite默认逐帧把加速度计方向用于重力修正，动态门控只有诊断显式启用；持续侧向加速度有被解释为倾角的风险。更高频候选的估计姿态RMS升至约3°，当前结果支持优先排查动态估计和串级环，不能只通过更激进轨迹寻找PCA胜出。

WLS轨迹的名义冻结可达性：所有候选静态正常优先级证书均为0；强偏航高频候选只有约0.00284%的主窗动态证书，即一个控制点，其余为0。这不是PCA闭环触发率，不能冒充真实PCA比较。
